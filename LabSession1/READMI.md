Sistem yang Dipilih

Program yang dibuat adalah Sistem Kasir Sederhana. Program ini digunakan untuk menampilkan daftar produk, memilih produk yang ingin dibeli, memasukkan jumlah pembelian, menghitung total harga, dan memberikan diskon jika memenuhi ketentuan.

Alur Program
1. Program menampilkan daftar produk yang tersedia.
2. Pengguna memilih nomor produk.
3. Program mengecek apakah pilihan produk valid.
4. Pengguna memasukkan jumlah produk yang ingin dibeli.
5. Program menghitung total harga berdasarkan harga produk × jumlah pembelian.
6. Jika total pembelian mencapai Rp50.000 atau lebih, pengguna mendapatkan diskon 10%.
7. Program menampilkan hasil pembelian berupa nama produk, jumlah, kategori, dan total pembayaran.
8. Jika pengguna memasukkan input yang tidak sesuai, program akan menampilkan pesan kesalahan.
   Output

Contoh output ketika pengguna memilih Nasi Goreng sebanyak 4:

===== SISTEM KASIR SEDERHANA =====

Produk ke-1<br>
Nama Produk : Nasi Goreng<br>
Harga       : Rp15000.0<br>
Kategori    : M<br>

Produk ke-2<br>
Nama Produk : Es Teh<br>
Harga       : Rp5000.0<br>
Kategori    : M<br>

Produk ke-3<br>
Nama Produk : Kopi<br>
Harga       : Rp8000.0<br>
Kategori    : M<br>

Pilih nomor produk (1-3): 1<br>
Jumlah beli: 4<br>
Anda mendapatkan diskon 10%.<br>
